Variable popover: inline edit (recommended)

Hover a {{variable}} for 400 ms or click it: a popover opens under the mark and edits the value in place. Enter saves the current value of the winning scope, Esc closes without saving. The initial value is shown read-only; it changes in Environments.

State a

Winner is the active environment Staging; the collection value it overrides is listed below the field. The field is focused on open so typing replaces the current value right away.

State d

Unresolved variable: quick add

"Not defined" in the danger red, with an inline add. "Add to" is a dropdown that lists every environment the collection allows (the active one first, marked, and preselected), then the collection and Globals; with no active environment it starts on the collection. The list opens inside the popover, so a click on a row is a click inside it. Unresolved marks use the danger role, not warning. The value becomes the initial value of the new variable; "Secret" sends it to the keyring instead.

Editing the field: marks kept, no popover

While the caret is in the field and keys are arriving, hover does not open the popover; marks keep their colors (T11) and update as you type. Clicking a mark while focused moves the caret; Alt+click or F2 on a mark opens the popover.
