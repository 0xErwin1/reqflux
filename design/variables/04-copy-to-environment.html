Copy variables to an environment

feedback-nov3 S13. Built on the workspace settings page of 01-settings-page.html; every frame is 900 px high and states stack top to bottom.

Select rows, then Copy to environment…

On the Globals and collection grids each row has a selection box and the header has one for all. The action sits in the section heading and stays disabled until a row is selected; it names how many. Empty values read in the danger tone (red), not warning. An environment's own page has neither the boxes nor the action.
